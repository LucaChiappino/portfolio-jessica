# Cartella Progetti

Inserisci qui le immagini dei tuoi progetti seguendo questa struttura:

```
public/projects/
├── project-1/
│   ├── cover.jpg          # Immagine di copertina
│   ├── image1.jpg
│   ├── image2.jpg
│   └── image3.jpg
├── project-2/
│   ├── cover.jpg
│   ├── image1.jpg
│   └── image2.jpg
└── ...
```

## Raccomandazioni per le immagini:

- **Formato**: JPG o WebP per foto, PNG per immagini con trasparenze
- **Dimensioni**: 
  - Cover: almeno 1200x900px (ratio 4:3)
  - Galleria: larghezza minima 1400px
- **Peso**: Ottimizza le immagini (max 500KB per immagine)
- **Naming**: Usa nomi descrittivi senza spazi (usa trattini: `soggiorno-moderno.jpg`)

## Tools per ottimizzare le immagini:

- TinyPNG (https://tinypng.com/)
- Squoosh (https://squoosh.app/)
- ImageOptim (Mac)
